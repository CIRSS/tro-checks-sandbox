# tro-utils-checks

This repository makes TRO declarations with
[`tro-utils`](https://github.com/transparency-certified/tro-utils), checks them using
[`tro-checks`](https://github.com/transparency-certified/tro-checks), and reports what it
found. The report for each target is listed in [`reports/README.md`](reports/README.md).

This repository does not define its own checks. It performs those defined by the
`tro-checks` module on candidates `tro-utils` generates from the resources in this repository.

The image installs the release of `tro-utils` named in
[`resources/TRO_UTILS_VERSION.txt`](resources/TRO_UTILS_VERSION.txt), and the candidates change
with that release only when it is changed there.

## Key files

| File | What it is |
| --- | --- |
| [`resources/`](resources/README.md) | The files the candidates are generated from, the arrangements among them. |
| [`generate-candidates.sh`](generate-candidates.sh) | Script that uses `tro-utils` to generate the candidates from the resources. |
| [`candidates/`](candidates) | The candidates generated by `generate-candidates.sh` and assessed by `tro-checks`. |
| [`candidates/manifest.json`](candidates/manifest.json) | Describes each candidate and lists the versions and tiers it targets. |
| [`reports/`](reports) | The reports of what the checks found. |
| [`Dockerfile`](Dockerfile) | Installs `tro-checks` and the release of `tro-utils` named in `resources/TRO_UTILS_VERSION.txt`. |

## Running it

In the top-level directory of this repository, check the candidates and regenerate the reports:

```
make generate-tro-reports
```

This checks the candidates as they are, so a candidate edited by hand is checked as edited. To regenerate the candidates with `tro-utils`, discarding any such edits:

```
make generate-candidates
```

These commands automatically download the Docker image they depend on if it isn't already on your machine. To later ensure you have the latest image, run `make pull-image`. After changing the `Dockerfile` locally, rebuild the image with `make build-image`.
